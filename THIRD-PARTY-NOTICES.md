# Fremdkomponenten

LibraryWarden bezieht folgende Pakete über NuGet. Sie sind nicht Teil dieses Repositorys, werden aber beim Bauen
(`dotnet publish … PublishSingleFile`) in die ausführbare Datei eingebunden.

| Paket | Lizenz | Quelle |
|---|---|---|
| Microsoft.Web.WebView2 | Microsoft-Lizenz für das WebView2 SDK (Weitergabe der Laufzeitbibliotheken erlaubt) | https://www.nuget.org/packages/Microsoft.Web.WebView2 |
| Microsoft.Toolkit.Uwp.Notifications | MIT | https://github.com/CommunityToolkit/WindowsCommunityToolkit |
| .NET Runtime / WPF / Windows Forms | MIT | https://github.com/dotnet |

Symbole in der Oberfläche stammen aus der Windows-Systemschrift *Segoe Fluent Icons* (bzw. *Segoe MDL2 Assets*);
die Schrift wird nicht mitgeliefert, sondern vom installierten Windows verwendet.

„GOG“, „GOG.com“ und „GOG GALAXY“ sind Marken von GOG sp. z o.o.; Spieletitel sind Marken ihrer jeweiligen Inhaber.
Sie werden ausschließlich beschreibend genannt.
